# public/assets/images

Owned/licensed course, instructor, and marketing images go here once available.

Until real assets are supplied, seeded course/instructor records reference the
same temporary external (hotlinked, third-party) image URLs the original
static page used — see `prisma/seed.js` and the project audit's "Hardcoded &
Dummy Data" section. Do not treat those URLs as production-ready; they must be
replaced with files in this directory (or a proper asset host) before launch.
